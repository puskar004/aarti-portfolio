About

From computer science theory to shipped products.

Aarti is a B.Tech Computer Science Core student at Lovely Professional University, Punjab, who leverages modern AI tools across the development lifecycle — from prompt engineering and code generation to UI design, debugging, and deployment.

That engineering mindset powers CampusSwap, a live student notes and books sharing platform built and deployed on Vercel. Aarti handled the product end-to-end: system design, responsive frontend with React and Next.js, search and categorization, and client deployment.

In addition to web software, Aarti has built hardware prototypes including an Arduino & ESP32-based Smart Home Automation System with an integrated web dashboard. Outside coding, she has planned and executed 3–4 large-scale college events at LPU, leading cross-functional teams, managing logistics, and coordinating with sponsors.
